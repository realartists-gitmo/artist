# Governance

Recommended roles are ontology editor, lexicography editor, domain reviewer, formal-semantics
reviewer, and release authority. A controversial change should retain the issue, evidence,
candidate analyses, rejected alternatives, selected analysis, reviewers, effective version, and
reconsideration trigger.

Rules:

- IDs are opaque and permanent.
- Released packages are immutable.
- Meaning changes create new IDs; label corrections do not.
- Automated proposals remain provisional until adjudicated.
- Evidence may inform a later release but must never silently rewrite an interpretation's pinned
  package snapshot.
